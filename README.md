# High-End Low-Poly Speaker System

### Project Description
This project is a high-fidelity speaker system utilizing an advanced 3D-modeled enclosure. The design features a low-poly geometric aesthetic on the exterior panels while transitioning internally into a high-end acoustic setup. By scaling the design down to a single central speaker driver module housed within a tall, skeletal internal bracing frame, the system mimics premium studio monitors. This configuration isolates the main speaker chamber, reduces cabinet resonance, and provides a structural framework to mount acoustic dampening panelling for clean, tight audio performance.

### How It Works
The speaker operates by taking an audio signal through rear-mounted binding posts which route directly into an internal amplifier board. This board powers the single high-efficiency driver module. The skeletal wooden frame surrounding the core speaker box absorbs structural vibrations and allows for thick acoustic foam installation, ensuring the speaker produces crisp, undistorted sound without muddy cabinet feedback.
